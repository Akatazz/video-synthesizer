🎛️ NDI Console Setup Guide

This synthesizer broadcasts a real-time NDI® video stream on your local network. Any NDI-capable lighting console, media server, or pixel mapper can receive it.

grandMA3 (onPC & Console)

  1. Navigate to Menu → Patch.
  2. Insert a Bitmap fixture (or add a Video element in the Media pool).
  3. On the Bitmap fixture encoder bar or Media window, set Input Mode → NDI.
  4. Under Source, select LZX-V Synth Output (or the name you assigned above).
  5. Assign the Bitmap fixture to your fixture layout view or 3D stage selection.
  6. Adjust Bitmap Dimmer, Scale, and Position as needed.
💡 Tip: Select a resolution that matches your fixture grid (e.g. "Matrix 256×256" for a 256-pixel LED array). Set Black Cutoff to 0.05 so background noise never causes LED fixtures to glow during blackout cues.

Resolume Arena / Avenue

  1. Open the Sources panel and navigate to NDI.
  2. Select LZX-V Synth Output from the discovered sources.
  3. Drag it onto a layer clip slot. The NDI feed will play in real time.
  4. Use Resolume's pixel-mapping (DMX Output) to route to your fixtures.

MadMapper

  1. Go to Inputs → NDI in the Media panel.
  2. Select the synthesizer's NDI source.
  3. Map the input to your fixture layout or DMX surface.

TouchDesigner

  1. Add an NDI In TOP operator.
  2. Set the Source Name to LZX-V Synth Output.
  3. Route the TOP output to your rendering / pixel-mapping pipeline.

NDI Studio Monitor (Testing)

  1. Open NDI Studio Monitor (free from ndi.video/tools).
  2. The synthesizer source will appear automatically on your LAN.
  3. Click to view the live feed — useful for testing before patching into your console.
💡 Network: Ensure the synthesizer PC and console are on the same subnet. NDI uses mDNS discovery (port 5353) and dynamic data ports (5960+). Firewalls must allow these.
